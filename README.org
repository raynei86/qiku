* Qiku - A chess library in Common Lisp

** Usage
This is at a functional stage where it passes ~perft~ up to depth 6 (last time I checked).
Exported symbols can be found in ~package.lisp~

** Migration naming (state -> position)
| Old (historical) | New (public API) |
|------------------+------------------|
| ~state~          | ~position~       |
| ~make-state~     | ~make-position~  |
| ~state-turn~     | ~position-turn~  |
| ~state-mailbox~  | ~position-mailbox~ |

** Performance and SBCL optimization notes
- Target benchmark remains ~perft(6)~ improvement from ~90s~ to ~60s~ on Thinkpad T480.
- SBCL-specific optimizations are acceptable for this project because the performance target is runtime-specific and ~perft~ is a hot path where SBCL type declarations and inlining can materially reduce allocation and dispatch overhead.
- Keep SBCL-specific tuning isolated to hot modules so portability can still be revisited later.

*** Creating positions
Still at a barebone stage, FEN strings will come soon.
#+begin_src lisp
(defparameter *test-position* (qiku:make-position)) ;; Initializes to default position
#+end_src

*** Moves and move generation
#+begin_src lisp
(defparameter *test-position* (qiku:make-position))
(let ((moves (qiku:generate-legal-moves *test-position*)))
  (loop
     for m in moves
     do ((do-move! (*test-position* m))
	 (undo-move! (*test-position* m)))))
#+end_src

*** Perft
#+begin_src lisp
(let ((*test-position* (qiku:make-position)))
  (qiku:perft *test-position* 5))
#+end_src
